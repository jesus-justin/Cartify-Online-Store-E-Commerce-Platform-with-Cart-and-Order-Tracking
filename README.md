# Cartify - Online Store with Cart and Order Tracking

Cartify is a PHP + MySQL storefront for tech gadgets and accessories. It features a curated product grid, cart flow, checkout, and order history/management pages with a modern, animated UI.

## Key Features
- Product catalog with search, sorting, and pagination
- Cart flow with quantity tracking
- Checkout that records orders and clears the cart
- Order history and management screens
- Responsive UI with subtle motion and bold visuals

## Local Setup
1. Import your database schema and sample data.
2. Update database credentials in Php/db_connect.php if needed.
3. Open Php/index.php in your local server (XAMPP or similar).

## Suggested Enhancements
- Add product categories and filters
- Add inventory and stock checks
